[download_futures_and_options.py](download_futures_and_options.py)

Этот скрипт автоматизирует загрузку и обновление исторических данных по фьючерсам и опционам на индекс RTS с Московской Биржи (MOEX), сохраняя их в локальной базе данных SQLite. Он поддерживает дозагрузку данных, ведёт логирование и защиту от сетевых ошибок.

# Основные возможности
 - Автоматическое создание и подключение к базе данных с двумя таблицами: Futures (фьючерсы) и Options (опционы).

 - Загрузка всех фьючерсов по RTS, начиная с заданной стартовой даты (по умолчанию 2019-01-01, если база пуста), с сохранением новых торговых дней и основных параметров инструмента.

 - Загрузка всех соответствующих опционов для новых дат, используя поле SHORTNAME в таблице фьючерсов.

 - Логирование действий в файл и цветной вывод в консоль для наглядного статуса и ошибок.

 - Автоматическая повторная попытка запросов к MOEX при сбоях (до 3 попыток с задержкой 10 секунд).

 - Поддержка VACUUM для оптимизации БД после завершения работы.

# Требования
 - Python 3.7+

 - Библиотеки: requests, pandas, apimoex

Установите зависимости с помощью pip:

```bash
pip install requests pandas apimoex
```
# Запуск
Скрипт запускается из командной строки:

```bash
python download_futures_and_options.py
```
База данных будет создана по пути, указанному в переменной DB_PATH (c:\Users\Alkor\gd\data_quote_db), и будет содержать две таблицы: Futures и Options.

# Настройки
 - Файл логов: rts_update.log

 - Фьючерсный тикер: RTS (можно изменить в переменной TICKER)

 - Стартовая дата: жёстко прописана в START_DATE_IF_EMPTY (по умолчанию 2019-01-01, можно изменить)

 - Путь к базе данных: задаётся переменной DB_PATH

# Особенности работы
 - Если база данных уже содержит записи, догружаются только новые торговые дни.

 - Для корректной загрузки опционов за декабрь 2017 — вручную замените значения SHORTNAME с RIH8 на RTS-3.18 в таблице Futures для дат начиная с 2017-12-21.

 - Скрипт логирует все действия, ошибки и результаты обновления в файл и выводит важные сообщения в цвете в консоль.

# Структура таблиц
## Futures

 - TRADEDATE (DATE): торгуемая дата

 - SECID (TEXT): идентификатор инструмента

 - OPEN, LOW, HIGH, CLOSE (REAL): параметры OHLC

 - VOLUME, OPENPOSITION (INTEGER): объёмы

 - SHORTNAME (TEXT): торговое имя

 - LSTTRADE (DATE): дата экспирации

## Options

- ID (INTEGER): уникальный идентификатор

- TRADEDATE (DATE): торгуемая дата

- SECID (TEXT): идентификатор опциона

- OPENPOSITION (INTEGER): открытый интерес

- NAME (TEXT): имя (корр. с тикером фьючерса)

- LSTTRADE (DATE): дата экспирации

- OPTIONTYPE (TEXT): тип (call/put)

- STRIKE (INTEGER): страйк
